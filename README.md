# Baby Shower Landing 🎀

Landing page inspirada en una invitación real creada para el baby shower de la hija de una amiga.

La idea nació como una forma de reunir en un solo lugar la información del evento, compartir algunos momentos especiales y organizar una lista de regalos para evitar que se repitan.

Esta versión pública funciona como **demo del proyecto**. Por privacidad, no incluye datos sensibles ni información real del evento.

## ¿Qué incluye?

* Invitación con fecha, horario y lugar de ejemplo.
* Galería de fotos.
* Galería con lightbox.
* Lista de ideas de regalos.
* Regalos disponibles y ya elegidos.
* Confirmación de asistencia por WhatsApp.
* Opción para agregar el evento al calendario.
* Música ambiental con opción para pausar.
* Cuenta regresiva del evento.
* Diseño adaptado a celulares y computadoras.

## Lista de regalos

La sección de regalos permite mostrar ideas, referencias y productos sugeridos para evitar repeticiones entre los invitados.

En esta demo, los datos están adaptados para mostrar el funcionamiento sin exponer información real del evento.

## Sobre la versión demo

Esta versión pública está pensada para mostrar el diseño y el flujo general de la landing, sin utilizar datos reales del evento.

Por ese motivo, los regalos de la demo no se guardan en una base de datos de producción. Las reservas pueden funcionar de forma visual o quedar guardadas únicamente en el navegador mediante `localStorage`.

Esto significa que:

* Si una persona marca un regalo como elegido, ese cambio no afecta la versión real.
* Las reservas de la demo no son compartidas entre todos los usuarios.
* Si se borra el almacenamiento del navegador, los datos de la demo pueden reiniciarse.
* La versión real del proyecto utiliza una base de datos separada para conservar las reservas correctamente.

La decisión permite mantener pública esta demo sin exponer datos sensibles ni afectar la organización real del baby shower.

## Privacidad

Este repositorio no contiene:

* Dirección real del evento.
* Teléfono real de contacto.
* Alias real.

* Información sensible de la familia.

La versión real del proyecto se mantiene privada.
