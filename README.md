# Landing Invitation Demo

Version publica demo de una landing de invitacion para eventos.

El proyecto esta preparado para mostrar el diseno, la navegacion y los flujos principales sin exponer datos sensibles, sin usar base de datos y sin depender de servicios externos.

## Que incluye

* Hero con informacion del evento.
* Galeria ilustrada con assets ficticios.
* Lista de regalos mockeada en memoria.
* Flujo de confirmacion por WhatsApp con destinatario demo.
* Archivo `.ics` de ejemplo.
* Diseno responsive para mobile y desktop.

## Privacidad

Esta version:

* usa nombres, contactos, direccion y alias ficticios;
* no consume `Supabase` ni otra base de datos en runtime;
* no muestra fotos privadas ni archivos reales de la invitacion original;
* reinicia el estado de regalos al recargar la pagina.
